# Concept: Partially Ordered Set
***
## Overview / Definition
%% 1-2 sentence simple definition of the concept. %%
A **partially ordered set** (or **poset**) is a set combined with a [[binary relation]] that indicates an order between some (but possibly not all) of its elements. That is, there is a notion that certain elements "precede/succeed" or "are smaller/larger than" other elements.

## Core principles / Key Characteristics
%% What is important to remember? %%
### Formal definition
A poset is an ordered pair $(P, \preceq)$ where $P$ is a set and $\preceq$ is a partial order relation, a type of [[binary relation]]. The partial order relation must be:
- **Reflexive:** every element is related to itself, $a \preceq a$.

# Concept: Directed Set
***
## Overview / Definition
%% 1-2 sentence simple definition of the concept. %%
A **directed set** $I$ is a [[Partially Ordered Set|partially ordered set]] where for every $i,j \in I$, there is $k \in I$ such that $k \geq i,j$. That is, every pair of elements (and indeed every finite subset) has a shared upper bound.
